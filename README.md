# 🌐 TopoSphere
### Visualize. Simulate. Master Networking.

**A next-generation browser-based network simulation and learning platform.**

Build network topologies, configure virtual devices, simulate protocols, inspect packet journeys, and troubleshoot network failures — all in one interactive workspace.

  <a href="https://toposphere.netlify.app/"><strong>🚀 Launch TopoSphere</strong></a>

## ✨ Features

- **Interactive Topology Editor** — Drag, connect, and design network architectures on an infinite canvas.
- **Device Library** — Routers, switches, PCs, servers, firewalls, and access points.
- **Network Simulation** — Ethernet, VLAN, ARP, IPv4, ICMP, DHCP, DNS, and static routing.
- **Interactive CLI** — Configure devices using Cisco-like terminal commands.
- **Packet Inspector** — Visualize packet movement, protocol headers, and forwarding events.
- **Smart Diagnostics** — Detect network configuration issues and troubleshoot failures.
- **Guided Labs** — Practice networking concepts through interactive CCNA-style exercises.
- **Project Management** — Save, import, export, undo, and redo network topologies.

## 🚀 Run Locally

**Requirements:** Node.js 20+ and npm.

```bash
git clone <your-repository-url>
cd toposphere
npm install
npm run dev
```

Open `http://localhost:5173`.

```bash
# Production build
npm run build

# Run tests
npm test
```
